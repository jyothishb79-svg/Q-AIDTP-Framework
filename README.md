# Q-AIDTP-Framework
Official repository for the AI-Driven Quantum Digital Twin Pancreas framework, designed for advanced quantum-biophysical simulations and metabolic stability tracking.

## Core Components
- `nso_surrogate.py`: Neural Schrödinger Operator (NSO) surrogate model for ab initio quantum-biophysical potential-energy calculations.
- `qisi_calculator.py`: Quantum Immune-Metabolic Stability Index (QISI) biomarker calculation module.
- `requirements.txt`: Essential Python dependencies.

- **MAE:** 8.4 mg/dL
